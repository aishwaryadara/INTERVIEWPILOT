# MVP Scope

## MVP Objective

Build a usable SaaS workflow where a technical interviewer can create a candidate, schedule an interview, run a live assisted interview, receive AI follow-up suggestions, and finalize a structured interview report.

## In Scope

- User authentication.
- Organization-based data separation.
- Candidate management.
- Interview scheduling.
- Live interview room.
- Transcript capture.
- Interviewer notes.
- AI follow-up question suggestions.
- AI summary draft.
- Rubric-based scoring suggestions.
- Interview report page.

## Out Of Scope

- Full ATS integration.
- Enterprise SSO.
- Multi-region infrastructure.
- Advanced analytics.
- Calendar integration.
- Bulk candidate import.
- Automated hiring decisions.
- Fully autonomous AI interviewing.

## MVP Quality Bar

- The product should feel like a real interview workspace, not a chatbot demo.
- Core flows should handle loading, empty, success, and error states.
- Backend logic should use controllers, services, repositories, DTO validation, and centralized error handling.
- AI output should be structured, editable, and tied to candidate evidence.
